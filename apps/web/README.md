# 手机前端

根目录运行 `npm ci`、`npm run dev`。Vite 将 `/api` 转发到本机 Worker 8787 端口；生产构建 `npm run build:web` 输出根目录 `dist/`，由 Cloudflare Static Assets 托管。

## 流程

相机或相册选图，浏览器按 EXIF 方向解码并生成长边不超过2560的 JPEG（质量0.94）；预览、旋转或裁剪后的实际图片与发送给 API 的图片相同。40MP/40MiB 以上源图拒绝并提示先用手机相册裁剪，编码后文件上限12MiB。HEIC/HEIF由浏览器可用解码能力处理，不支持的浏览器提示转换为JPEG，不会上传一个无法预览的文件。

默认识别整图。用户可通过“裁剪”的四边滑块手动选择要识别的区域；前端对本次规范化整图执行真实像素裁剪并重新编码JPEG，发送裁后图，结果框直接使用裁后坐标。此功能不自动寻找手牌、不调用模型或真值；选区内所有可见的牌均属于识别目标。

本次规范化整图仅保存在内存中，用于重开选区、取消编辑、重置和恢复整图；重裁始终基于整图，不连续裁剪已裁结果。区域边界保存为整数像素对应的比例，旋转时同步旋转整图及选区，避免取整累积漂移。选择新照片会丢弃旧选区；过期异步裁剪不会覆盖新照片或关闭新选区对话框。新照片、移除与卸载会释放不再使用的Blob URL。

`POST /api/recognize` 使用 multipart `image` 字段。类型见 `src/types.ts`：bbox 为服务器返回图片的 `[x,y,width,height]` 像素坐标，classId使用原始数据标签。响应先经运行时合同校验才展示框。z/h中文映射经固定v2数据联系页视觉核对（h顺序春夏秋冬梅兰菊竹）。

请求无自动重试；客户端等待65秒，切换或移除照片会取消旧等待，并用generation防止迟到响应覆盖新照片。取消前端等待不代表服务器已停止计算。网络恢复仅启用入口，不重发识别。照片不存localStorage、IndexedDB、缓存或持久后端；本模块不包含service worker。

结果支持牌框与列表、低置信核对、逐张人工修改与移除。修改明确标记，可撤销，不用于报告模型自动准确率；没有虚构进度百分比或整手准确率。

## 验证

- `npm run typecheck`：前端和Worker的类型检查。
- `npm test`：包含前端响应合同与请求错误、不自动重试、选区像素边界、非法/微小选区拒绝、旋转像素对应和四次旋转不漂移。
- `npx playwright install chromium` 后运行 `npm run test:e2e`：320/390/430px无横向溢出、牌按钮至少44px、上传/结果/人工修改/旋转、取消与迟到响应、429、离线恢复；另验证320px裁剪控件至少44px、选区取消/重开/重置/恢复、真实multipart JPEG尺寸和选中区域像素、异步旧裁剪不能覆盖新图。
- 本次截图：根 `artifacts/web/screenshots/`。测试图片和识别响应是明确的合成合同fixture，不是模型准确率或真实手机相机测试。

真实设备Safari/Chrome、手机HEIC原图、慢网和真实GPU端点仍需整体验收。浏览器仿真不能替代设备相机权限和现场拍摄验证。
