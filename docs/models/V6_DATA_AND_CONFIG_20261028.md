## 每组模型配置

全部从签名V5父权重独立微调，重置优化器，最多12个新epoch；AdamW，初始学习率5e-5，seed2026。定位器目标有效batch32；分类器物理batch16、累积2。全部只使用train/valid，不重开旧sealed test。

前5组是单类牌面定位器，评估配固定Eff-last 42类分类器；后3组训练分类器，评估配固定V26-last定位器。所有组均用实际预测框做整手验证，不以真值裁图的分类正确率冒充端到端效果。

定位器V8三支用同一父best，V26两支用同一父last；分类器三支用同一Eff-last。YOLO1280以较小物理batch适应12GB显存，因此BatchNorm批统计也可能影响比较。分类保留完整牌面、quarter-turn，不镜像；相机扰动扩画布避免裁掉字形。

## 首组结果与下一步

首组训练25.08分钟，完整150图验证，两组checkpoint均无推理失败。相同CPU、相同Eff-last与相同阈值下，自动整手70/82→71/82，模型全对72/82→74/82；但13/14牌子组43/45→42/45。last仅67/82，且接受了4张错误。loss持续下降并不代表整手继续改善。该结果尚未做GPU部署验收，不替换线上V26模型。

下一获准窗口先完成原剩余7组，优先测清背景负样本、背景加几何以及960→1280的收益。当前错误仍以背景误检和小牌漏检为主；3张正确却拒识的图均卡在检测融合置信度，单纯扩大分类器或全局降阈值缺乏依据。

后续研究按结果安排：

1. 当前7组保留best/last整手选择与13/14子组。之后可另做保存若干阶段checkpoint、按整手指标选优的对照，减少仅靠定位AP保存best而错过潜在整手最佳轮次的风险。
2. 用固定更新步数比较主集2629与扩展4671，保持train/valid来源不变；不把更多同源增强当作新场景。
3. 比较按来源组／多牌照片均衡采样与现有采样，关注单牌图过半和花牌稀缺，报告类别召回与整手拒识。
4. 补充新牌桌、麻将样式与光照的手机整手标注，单独留出独立来源验证；已有257张未标注手机图片当前不计训练。
5. 若拒识仍集中于低检测分数，在valid来源分组下研究校准，检查错误接受率；不靠降低门槛宣称准确率提升。
6. 若背景误框仍是主因，可新设分类器“非牌面拒识”对照：仅从train挖掘并人工核验检测假阳性，比较原42分类与含内部背景拒识的分类器。对外仍只输出42种牌，必须同时检查白板召回，避免把难牌都当背景删掉。这是后续假设，尚未实现或加入当前已冻结7组。
