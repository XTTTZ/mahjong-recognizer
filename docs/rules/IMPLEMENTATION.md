# 附图136张规则的实现口径

来源为用户提供的《广东大牌麻将136张翻倍图》。未用外部麻将规则补写牌型。用户明确选择“兼容牌型相加，按表排除重复项”；下面同时记录表内事实和本工具为消除歧义采用的口径。

## 输入、结构、起胡

`analyzeHand`输入全部实体牌，包含已经声明的碰/明杠/暗杠；不能只传剩余暗手。规范牌值为1–9m/p/s、1–7z；现有应用字牌顺序为东南西北白发中。花牌、牌背、第五张同牌、消耗不存在实体牌的声明均为无效输入。

声明后从实体牌中扣除3/4张，再枚举剩余的全部“四副刻/顺+一对将”分解。总数为14+已声明杠数。未声明的四张不自动算杠；七对中四张算两对。七对无副露时按0/1/2/3种四张分别取4/8/16/32，不能叠加较低档。十四张以下是尚不成胡；多余牌且没有对应杠声明要求核对。

普通结构本身基数0，无鸡胡。门清等手动加项可把它加到3；中码不凑起胡。最终为`（兼容基准项+确认的上下文项+本桌附加）×（1+中码数）`。自摸或抢杠本身不自动+3。无效/未成胡不输出可结算总倍数。

## 去重和兼容

- 混碰6替代混色3+碰碰3；清碰9替代清色6+碰碰3；混七对7替代基本七对4+混色3。相同基础不再重复相加。混龙固定6，混幺九固定9，不能误读相邻合并单元格为7/10。
- 七对系列只取相应档或连七对16/大七星24完整升级；连七对不再加清色，大七星不再加字色。普通清七对为4+6=10，清豪七为8+6=14，是用户选择的兼容相加解释。
- 混/清/字/红/绿/蓝属于同一颜色族，重叠取最高，不把同色20+20堆叠。
- 小/大三元不计普通碰碰及混色；只有本手另外构成真正混碰，才额外+3。七对中的四张不是杠/普通刻子，不能因此再送混碰3。
- 普通七对/豪七不带三元四喜。双豪、三豪允许三元；三豪允许四喜。双豪小三元为16+9=25；三豪大三元加非幺九数牌对子为32+16=48；若该手还满足混幺九，按兼容口径另加9成为57。
- 三豪由三种风牌四张与第四风对子组成时，可同时满足小四喜和字一色，按用户确认口径为32+16+20=68。不是把示例48当封顶。
- 标准分解与七对是不同和牌解释；计算最高兼容的一种解释，不把标准刻顺将专属的绿一色等硬加到七对解释上。
- 九莲与清龙的交叉、十八罗汉与四暗刻的升级，表未逐字列全。本工具按共用基础/同刻杠系列去重，并在返回的warnings/exclusions明确标为工具口径，不声称是图片明文。其他本桌约定可使用明示附加项。

## 缺历史的信息由用户确认

四暗刻、单骑、十三幺飞、九面听、门清、海捞、杠开、天胡/地胡均不从照片猜测。声明碰/明杠会限制四暗刻和门清；提供和牌张时，会核查单骑、飞/九面听的结构条件，但条件吻合也不自动启用。

天胡/地胡互斥，按用户选择作为独立50倍加项兼容相加，不作为静默替换全部牌型的固定总分。七对系列/十三幺/四暗刻不计门清。其他失效勾选返回排除理由，不把原本合法的牌面本身变成错误牌面。

只十三幺可抢暗杠；抢杠按自摸结算的支付关系、包三家、漏胡漏碰、码跟庄、连庄加码数量，仍需要局面历史。本引擎只计算用户确认后的倍数，不自动判断付款责任或生成赢钱金额。

## API与验证

纯函数入口为`analyzeHand`→用户勾选→`calculateScore`，或`scoreHand`快捷调用。输出包含结构是否合法、基准牌型、确认加项、排除证据、未满3倍标记及最终公式。输入和勾选数组均不修改。

独立单元测试覆盖47种以上有区别的情形，包括多个标准分解、完整实体杠、未声明四张、七对档位及⑥⑦例外、68组合、十三幺抢暗杠、手动项失效、普通自摸0、门清3、先相加再乘码、数值安全和同系列排斥。
